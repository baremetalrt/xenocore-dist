    Console commands¶

    Programmer · reference · C++

    Generated from source — do not edit by hand.

    This page is written by Docs/Manual/tools/gen_reference.py from the plugin's headers. Edit the source comment and re-run the generator instead. See Docs/Manual/tools/README.md.

    Console variables and commands XenoCore registers, and its Exec functions. Open the console in Play-In-Editor with the backtick key (`).

    Development builds only

    These are testing tools. Cheat-flagged variables and cheat-manager commands are not available in a Shipping build. Do not build gameplay on them.

    Console variables¶

    Exec functions¶

    An Exec function is typed into the console by its name followed by its arguments. Unreal only routes console input to a fixed set of objects: the player controller, its cheat manager (and cheat-manager extensions), the possessed pawn, the HUD, the game mode and the game instance. An Exec function on a component or a subsystem is not on that list, so typing it is expected to print Command not recognized.

    A row marked Yes is declared on a cheat-manager extension, which registers itself on every new cheat manager, so it is typed like any built-in cheat. Exec functions are compiled out of Shipping builds.

    Command Arguments Declared on Reachable from the console Description
    XenoArts UXenoCoreProgressionCheats Yes, in development builds XenoArts - the leader's learned arts and palette.
    XenoAwardExp <Amount> UXenoCoreProgressionCheats Yes, in development builds XenoAwardExp 5000 - bank EXP without finding something to kill.
    XenoAwardGold <Amount> UXenoCoreProgressionCheats Yes, in development builds XenoAwardGold 500 - bank gold without a quest to finish.
    XenoCastArt <ArtName> UXenoCoreProgressionCheats Yes, in development builds XenoCastArt AirSlash - cast an equipped art by spec handle, the palette's own dispatch.
    XenoCoreDumpInventory UXenoCoreSystemCheats Yes, in development builds XenoCoreDumpInventory - read-only dump of the bag, the leader's loadout and totals.
    XenoCoreTestInventoryEvents UXenoCoreSystemCheats Yes, in development builds XenoCoreTestInventoryEvents - mutates: adds and removes one item, reports both messages.
    XenoDownMember <ActiveSlot> UXenoCoreSystemCheats Yes, in development builds XenoDownMember 0 - kill an active member through the real damage path.
    XenoGaugeAdd <Amount> UXenoCoreSystemCheats Yes, in development builds XenoGaugeAdd 100 - add Party Gauge points (negative removes).
    XenoGaugeSpend <Bars> UXenoCoreSystemCheats Yes, in development builds XenoGaugeSpend 1 - spend whole Party Gauge bars through the real path.
    XenoGiveAP <Amount> UXenoCoreProgressionCheats Yes, in development builds XenoGiveAP 1000 - Art Points for the leader.
    XenoGiveSP <Amount> UXenoCoreProgressionCheats Yes, in development builds XenoGiveSP 500 - pour SP into the leader's selected skill branch.
    XenoHurtParty <Fraction>=0.3f UXenoCoreSystemCheats Yes, in development builds XenoHurtParty 0.3 - set every standing member to that fraction of max HP, to watch out-of-battle recovery.
    XenoLevelUpLeader UXenoCoreProgressionCheats Yes, in development builds XenoLevelUpLeader - award exactly the EXP the leader needs for their next level.
    XenoLevelUpParty UXenoCoreProgressionCheats Yes, in development builds XenoLevelUpParty - award enough EXP that every active member levels at least once.
    XenoLoad <SlotIndex>=1 UXenoCoreSystemCheats Yes, in development builds XenoLoad 1 - load a slot.
    XenoQuestStatus UXenoCoreSystemCheats Yes, in development builds XenoQuestStatus - print every quest this party has touched.
    XenoReviveMember <ActiveSlot> UXenoCoreSystemCheats Yes, in development builds XenoReviveMember 0 - bring that member back at full health.
    XenoSave <SlotIndex>=1 UXenoCoreSystemCheats Yes, in development builds XenoSave 1 - save to a slot.
    XenoSaveDump UXenoCoreSystemCheats Yes, in development builds XenoSaveDump - print every slot without loading it.
    XenoSetArt <SlotIndex> <ArtName> UXenoCoreProgressionCheats Yes, in development builds XenoSetArt 2 AirSlash - put an art in a palette slot.
    XenoSetLeader <ActiveSlot> UXenoCoreSystemCheats Yes, in development builds XenoSetLeader 0 - make an active slot the leader.
    XenoSkills UXenoCoreProgressionCheats Yes, in development builds XenoSkills - the leader's branches and progress.
    XenoWipeParty UXenoCoreSystemCheats Yes, in development builds XenoWipeParty - down every active member, which triggers the party-wipe flow.
