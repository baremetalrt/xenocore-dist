    Data assets¶

    Designer · reference · No code

    The data asset types a designer creates and fills in, and the three item fragments that go on an item definition. To make a new one, right-click in the Content Browser, choose Data › Data Asset, and pick the class from the list.

    Duplicate, don't start blank

    For item definitions especially, duplicate a working shipped asset into your own folder (Content/MyGame/...) rather than creating an empty one. A blank asset has none of the links the shipped ones carry, and several of those fail without an error.
