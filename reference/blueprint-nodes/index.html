    Blueprint nodes¶

    Designer · reference · No code

    The Blueprint nodes XenoCore adds that are not member functions of a class: latent nodes (they wait for the player and continue from one of several output pins) and function libraries (nodes you can place in any graph). Search the node's name in the graph's right-click menu. Member functions of components, subsystems and widgets are listed with their class in C++ classes.

    Latent nodes¶

    Each latent node fires at most one of its output pins, once. A graph waiting on one is suspended until then, so always wire every output pin you care about.

    • Ask Confirm, Offer Quest, Open Shop and Open Trade always fire one: if their screen cannot be shown, or closes without an answer (backed out of, or torn down with the world), they take the No / Declined / Nothing Changed / Cancelled pin.
    • Show Dialogue and Play Dialogue fire nothing if the conversation is closed (by Close Dialogue from another graph, or the world ending) before the line is advanced. The graph waiting on them simply stops there.

    Offer Quest¶

    Latent node · XenoCore › Quest · class UXenoCoreOfferQuest · header XenoCoreRuntime/Public/Quest/XenoCoreQuestNodes.h

    "Offer Quest" - puts the quest panel on screen and continues on the player's answer.

    Input pin Type Description
    Quest UXenoCoreQuestDefinition* What to offer. Null completes on Declined immediately, with a warning.
    Giver AActor* Whoever is asking. Used only for the "Requested By" line when the quest names no requester of its own; safe to leave null.
    Output pin Carries Fires when
    Accepted — The player took the quest on. It is Active by the time this fires.
    Declined — The player turned it down, backed out, or the panel could not be shown.

    Latent node · XenoCore › Shop · class UXenoCoreOpenShop · header XenoCoreRuntime/Public/Shop/XenoCoreShopNodes.h

    "Open Shop" - puts the shop on screen and continues when the player leaves it.

    Input pin Type Description
    Table UXenoCoreShopTable* What the shop sells. Null still opens the shop for selling, with a warning.

    Open Trade¶

    Latent node · XenoCore › Trade · class UXenoCoreOpenTrade · header XenoCoreRuntime/Public/Trade/XenoCoreTradeNodes.h

    "Open Trade" - puts the barter screen on screen and continues when the player is done.

    Input pin Type Description
    Table UXenoCoreTradeTable* What they will part with. Null completes on Cancelled immediately, with a warning - the same "authoring mistake, not a crash" contract Offer Quest keeps.

    Output pin Carries Fires when
    Traded — At least one exchange happened.
    Cancelled — The player backed out, or the screen could not be shown.

    Latent node · XenoCore › Dialogue · class UXenoCorePlayDialogue · header XenoCoreRuntime/Public/Dialogue/XenoCoreDialogueNodes.h

    "Play Dialogue" - a whole run of lines from an array, then closes the box.

    Input pin Type Description
    Lines const TArray<FXenoCoreDialogueLine>& Played in order. An empty array completes immediately and logs a warning.
    Output pin Carries Fires when

    Show Dialogue¶

    Latent node · XenoCore › Dialogue · class UXenoCoreShowDialogue · header XenoCoreRuntime/Public/Dialogue/XenoCoreDialogueNodes.h

    "Show Dialogue" - one sentence, one node, an exec pin that fires when the player presses A. Does not close the box: end the chain with Close Dialogue.

    Input pin Type Description
    Speaker FText The name on the plate. Leave empty to keep the previous speaker.
    Line FText One sentence.
    Source EXenoCoreDialogueSpeaker Whose head the box floats over. Npc means the actor that was interacted with - the subsystem already knows which, so there is no actor pin to wire.
    Output pin Carries Fires when
    Advanced — Fires when the player advances past this line.
