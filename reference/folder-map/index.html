    Folder map¶

    All · reference · No code

    Every folder in the XenoCore plugin's content, what it holds, and whether you can remove it when you replace the sample. In the Content Browser this is Plugins › XenoCore Content (turn on Show Plugin Content first). On disk it is Plugins/GameFeatures/XenoCore/Content/ in your project.

    Kind tells you what removing a folder costs:

    • Framework: bases, shared effects and screens the systems need. Keep it. Duplicate from it.
    • Sample: example content that shows the framework working. Replace it with your own, then delete it once nothing of yours references it.

    Where is…?¶

    The settings designers reach for most, and the one asset each lives on. Paths are inside XenoCore Content.

    Delete with the reference viewer, not by eye

    A folder marked Sample can still be referenced by a framework asset (an ability set that grants a sample art, a party roster that lists a sample member). Before deleting, right-click the folder › Reference Viewer, or use Delete and read the list of referencing assets the editor shows you. See Replace the sample content.

    Not in your copy¶

    The plugin is developed alongside a development-only test folder that is removed before release. If you see /XenoCore/Dev under Directories to Never Cook in your packaging settings, that line is harmless; leave it or delete it.

    Reimport is not available on some retargeted clips

    The retargeted clips in Characters/Player/Animations/Mixamo and two get-up clips in Characters/Player/Animations/Reactions record a development folder as their import source. That is editor-only metadata: the clips load and cook normally. Only Reimport on those clips fails, because the source files are not included.

    Outside the plugin¶

    Location What it is Yours to change?
    Content/ Lyra's own content: mannequins, UI toolkit, shooter sample No; reference only
    Plugins/GameFeatures/ (other folders) Lyra's sample game features (shooter modes) No
    Plugins/GameFeatures/XenoCore/Config/Tags/ XenoCore's gameplay tags ini No; add your own tag file
    Plugins/GameFeatures/XenoCore/Source/ XenoCore C++ Subclass, don't edit
    Plugins/VRM4U/ The VRM4U plugin the VRoid party needs No
