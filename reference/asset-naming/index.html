    Asset naming¶

    All · reference · No code

    The prefixes XenoCore's content actually uses, so you can tell an asset's type from its name in the Content Browser. Most follow Lyra's own conventions; a few are XenoCore's. XenoCore-authored assets also carry XenoCore after the prefix (GA_XenoCore_TargetMode), which keeps them apart from Lyra's assets of the same kind in search results.

    Counts are of the plugin content you receive (Plugins/GameFeatures/XenoCore/Content, including Imported/, excluding Dev/, which is removed before packaging), measured on 2026-10-14. Counts change as content is added.

    The VRoid character folders also hold importer-generated assets with the importer's own prefixes (VM_, VL_, VA_, SP_, POSE_, A_). Leave those names alone; the importer expects them.

    VRoid characters use the importer's mesh and skeleton prefixes, which clash with Lyra's

    Lyra, and everything else in this project, names a skeleton SK_ and a skeletal mesh SKM_ (SK_Mannequin, SKM_Manny; SK_GoldSword, SKM_GoldSword). The VRoid importer names a skeletal mesh SK_ and a skeleton SKEL_, so in Characters/VRoid/<Name>/Mesh/, SK_AvatarSample_L is Kael's mesh and SKEL_AvatarSample_L is his skeleton. The sample characters keep the importer's names for now. Go by the asset type shown in the Content Browser, not by the prefix. Name your own non-VRoid assets the Lyra way.

    Exceptions you will see¶

    • BP_ and B_ both mean Blueprint. Lyra uses B_; some XenoCore Blueprints use BP_ (BP_XenoCore_Party, BP_XenoCore_Progression, Inventory/Loot/BP_XenoCore_TreasureChest, Battle/Attributes/BP_XenoCoreDamageExecution). There is no difference in kind.
    • Party member definitions have no type prefix (PartyMember_Blue), unlike every other data asset (DA_).
    • Retargeted clips keep their source names (Characters/Player/Animations/Mixamo/Getting_Up_retargeted).
    • Some asset names still contain placeholder names that will change before release. The manual writes them as they appear today so you can find them.

    For your own content¶

    Use Lyra's prefixes (B_, GA_, GE_, W_, DA_…) and your own project tag in place of XenoCore (GA_MyGame_Fireball), under Content/MyGame/. Then a search for your tag finds only your assets, and a template update never collides with your names.
