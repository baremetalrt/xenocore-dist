# XenoCore

Xenoblade Chronicles-style party combat, menus and world systems for **Unreal Engine 5.8**, built as a
Lyra Game Feature plugin.

This repository hosts what we hand out. The source lives elsewhere.

- **Manual:** https://brianhabana.github.io/xenocore-dist/
- **Latest demo build:** https://github.com/brianhabana/xenocore-dist/releases/latest
- **All releases:** https://github.com/brianhabana/xenocore-dist/releases

## Reporting a problem

Open an issue here with what you did, what you expected, and the log
(`Saved/Logs/` in your project, or next to the demo's executable).
