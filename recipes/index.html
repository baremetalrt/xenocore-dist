    How-to recipes¶

    Designer and Programmer · Last tested: never

    Each recipe does one task from start to finish. It lists what you need, gives one action per step, and ends with Test it (what to press in Play and what you should see) and If it doesn't work (the symptom and the fix, including the failures that happen without any error).

    Find your task in the tables below. What you get is what you will see in Play when you finish. Code says whether you need anything beyond the editor: No means the Details panel, Data Assets, Data Tables and, at most, a few simple Blueprint nodes. C++ means a programmer.

    New to the template? Do the Getting Started tutorials first: Your first change, Your first art and Your first enemy. They cover the most common tasks with more explanation than a recipe gives. Unfamiliar words are in the Glossary.

    Work in your own folder

    Every recipe puts new assets under Content/MyGame/… and duplicates shipped assets rather than editing them. Where a recipe has to edit a shipped asset, it says so; note those changes so you can reapply them after a template update.

    Times are for a first attempt with the editor already open.

    Most common tasks¶

    • New character: Add a party member, then Set the starting party.
    • New attack: Create an attack art.
    • New enemy in the world: Add an enemy type, then Place enemies.
    • New item: Add a weapon, Add an armour piece or Add a consumable item.
    • New NPC: Write an NPC conversation, then Create a collection quest.
