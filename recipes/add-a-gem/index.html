    Add a gem¶

    Designer · 10 min · No code · Last tested: 2026-10-05

    Result: a new gem the party can find, carry, and fit into weapons and armour from the Equipment screen. Its strength is rolled when it is found, and it raises one stat on whoever wears it.

    How gems work¶

    • A gem is an item in the Gems tab. One item per kind and rank: Strength Up I, Strength Up II.
    • Strength is rolled per gem. The item gives a range (Strength Up I: 5-10); every copy found rolls its own number inside it, so two Strength Up I can read +6 and +9.
    • Gems sit in the equipment, not the character. Hand a gemmed sword to someone else and the gems go with it. A weapon has up to 3 sockets, an armour piece up to 1 - so 8 gems per character at most.
    • Each kind has a cap per character. Strength Up stops adding at +150 however many are worn.
    • Permanent gems are fitted to an item when it is made and can never be removed.

    Make a new gem¶

    1. Duplicate an existing gem in /XenoCore/Inventory/Gems, e.g. ID_XenoCore_Gem_StrengthUp_I. Never create an item Blueprint from blank - it would be missing its fragments.
    2. Open it and set Display Name (include the rank: Ether Up IV).
    3. In Fragments, find XenoCore Fragment Gem and set:
    4. Gem Id - a number no other gem uses. The shipped ones are kind x 10 + rank (Strength Up I is 101). Never change an id once players have socketed the gem - the socket stores the number.
    5. Rank, Stat Tag (the XenoCore.Stat.* it raises), Min Value / Max Value, Cap.
    6. A percent stat (Critical Rate) is entered as whole percent: 4 means +4%.
    7. In XenoCore Fragment Item Category set Sell Value and Rarity; keep Category = Gems. In XenoCore Fragment Item Display, Symbol Colour is the gem's colour on the Equipment screen. The shipped gems use their XC1 element: Strength Up red, Ether Up yellow, Agility Up green, Ether Def Up cyan, Muscle Up and Critical Up orange.
    8. Open DA_XenoCore_GemRegistry and add the gem to Gems. ⚠️ A gem missing from the registry can be carried but not socketed - the game refuses and logs why.
    9. Put it somewhere the player can get it: a quest reward or a shop. The shipped game keeps gems out of chests, as XC1 does; a chest pool in a drop table works if you want them there.

    Give equipment sockets¶

    • Weapons get sockets from their weapon type. Every weapon type asset (e.g. DA_XenoCore_WeaponType_Greatsword) has Default Gem Slots = 2, so a new weapon has two sockets with nothing to set. Change it there to change every weapon of that type.
    • One weapon different? On the weapon item, in XenoCore Fragment Equip Slots, tick Override Gem Slots and set Gem Slots (0-3).
    • Armour sets Gem Slots on its own Equip Slots fragment: 0 or 1.
    • Fixed Gems - permanent gems, filling sockets 1, 2, 3 in order. Each names a gem and its value.

    Check it¶

    • Data Validation on DA_XenoCore_GemRegistry flags a duplicate or zero id, a gem with no stat, and a min above its max.
    • In play, open Equipment, move right onto the Gems column, press A, pick a slot, pick a gem. Highlighting a gem previews the change on the character's stats; picking it applies it. The column draws one icon per gem in its colour and a dark icon per empty socket, and the gem names are on a line under the piece, in the popup, and in the Item Details tab's GEMS section.
    • The socket icons are set in Project Settings > XenoCore UI > Items (Gem Socket Filled Icon, Gem Socket Empty Icon). Clear them and the column draws text instead.
    • The popup's look is W_XenoCore_GemPopup (Project Settings > XenoCore UI > Gem Popup) - restyle it there.

    Limits¶

    • A gem's Stat Tag must be one GE_XenoCore_EquipmentStats has a modifier for; otherwise the game warns that the gem adds nothing. Adding a stat there is a programmer job (Equipment stat).
    • Gems that do something other than add to a stat (Aggro Up, HP Steal, EXP Up) are not supported yet.
