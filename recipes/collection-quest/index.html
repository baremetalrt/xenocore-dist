    Offer a collection quest¶

    Designer · 30 min · No code · Last tested: never

    Result: an NPC with a marker over their head offers a quest to bring them three of an item. The quest appears on the HUD tracker and in the Quest Log, counts as the party picks the items up, and pays gold, EXP and an item when handed in.

    Before you start¶

    • Give an NPC a conversation.
    • Quests.

    How a quest is put together¶

    A quest is one data asset of class XenoCoreQuestDefinition. The sample is Quests/DA_XenoCore_Quest_Collection01, which asks for two ID_XenoCore_EtherCrystal. In L_XenoCore_Gym it is given by the placed NPC NPC_QuestGiver; Characters/NPC/B_XenoCore_Npc_Sample carries it too, as a ready-made example.

    The NPC's default On Interact graph already runs the whole quest, so a collection quest needs no graph: you set the NPC's Quest and fill in its line lists. What the default graph does:

    When the player talks and the quest is… The NPC plays Then
    Not yet taken (or declined before) Dialogue (the greeting) Shows the offer panel
    …and the player accepts Accepted Dialogue The quest is active
    …and the player declines Declined Dialogue The quest can be offered again later
    Taken, not finished In Progress Dialogue Nothing
    Taken, every objective met Turn In Dialogue Takes the items and pays the reward

    Any empty list falls back to Dialogue.

    Counting is automatic. The party's bag is re-read whenever it changes, and the count is set from it. Items the party already holds when it accepts count straight away, so a quest can be ready to hand in the moment it is accepted.

    Steps¶

    1. Create the quest¶

    1. Duplicate Quests/DA_XenoCore_Quest_Collection01 into MyGame/Quests. Name it DA_MyGame_Quest_LampOil.
    2. Open it and set, under XenoCore › Quest:
    Setting Value What it does
    Title Lamp Oil The offer panel's title, the log and the tracker
    Kind Collection A label for the panel and the log. It changes no behaviour.
    Area Riverside Where the log groups it
    Requester Name (empty) Empty uses the giver's Display Name
    Requester Portrait optional The face beside "Requested By"
    Summary The lamplighter has run dry... The paragraph on the offer panel
    Can Decline Ticked Unticked shows only Accept

    2. Set the objective¶

    In Objectives, edit the one entry:

    Setting Value
    Description Bring 3 Scrap Plating to the lamplighter.
    Kind Collect Item
    Item Target ID_XenoCore_ScrapPlating
    Required Count 3
    Counter Label (empty): the counter row uses the item's name, "Scrap Plating 0/3"
    Consume On Turn In Ticked: the three are taken when the quest is handed in
    Icon Source From Item

    A quest can have several objectives; all must be met.

    3. Set the reward and gates¶

    1. Reward: Gold 300, Experience 150, Items: add ID_XenoCore_BlueSword once. Each entry in Items is one item; add an entry twice for two. Skill Branches can also open a character's skill branch, as XC1's later branches arrive.
    2. Gates (optional): add Party Level At Least with Required Level, or Quest Completed with a Required Quest. A gated quest shows no marker and cannot be offered until every gate holds. Gates are checked only when offering.
    3. Save. If the editor reports a validation error on save, read it: a missing Item Target or a Required Count of 0 means the quest can never finish.

    EXP goes to the party, and gold to the party's purse. Benched members earn none by default (Reserve Experience Rate 0 on Game/BP_XenoCore_Progression).

    4. Give it to an NPC¶

    1. Place a Characters/NPC/B_XenoCore_Npc, or select one you placed.
    2. Under XenoCore › NPC, set Display Name and set Quest to DA_MyGame_Quest_LampOil. Leave Has Quest off: with Quest set it is ignored, and the quest decides the marker.
    3. Under XenoCore › NPC › Dialogue, fill in:
      • Dialogue: the greeting before the offer.
      • Accepted Dialogue, Declined Dialogue, In Progress Dialogue, Turn In Dialogue.
    4. Save the level.

    With Quest set, the marker over the NPC follows the quest by itself: it shows while the quest can be offered or is ready to hand in, and disappears while the quest is in progress.

    Test it¶

    1. Press Play and walk up to the NPC. The marker is over their head.
    2. Talk. The greeting plays and the offer panel opens. Accept.
    3. The tracker shows "Scrap Plating 0/3".
    4. Pick up or loot three Scrap Plating (every minion family's chests can hold it). The count rises each time.
    5. Return. The marker is back. Talk: the turn-in lines play, the reward banner shows 300 G, 150 EXP and the sword, and the three Scrap Plating leave the bag.

    If it doesn't work¶

    Fails silently: the count sticks at 0

    Item Target is a different item from the one being picked up. Check that it is the exact item definition (not a duplicate with the same display name). Every change to the party's bag refreshes the count, including changes made with Lyra's own inventory nodes, which XenoCore notices and announces on their behalf.

    The marker never appears

    A gate is not met (the level is too low, or the required quest is not handed in), or the quest was already completed in this save. Quest progress is saved, so an old save remembers it.

    The item was spent before handing in

    Selling or trading away the items drops the quest back to in progress, because the count is read from the bag each time. Only Consume On Turn In takes them.
